# Phase 1: language-guided reproductions

This directory contains the reproducibility layer for LViT-T, RecLMIS, and
ProLearn. The repositories under `upstream/` are immutable inputs. All dataset
adapters, environment compatibility work, launchers, and evaluation code must
live here or in another top-level Phase 1 directory.

Step 1.1 records the pinned sources and the first unmodified environment-build
attempts. No model source, architecture, objective, pretrained parameter, or
text-processing behavior has been changed.
