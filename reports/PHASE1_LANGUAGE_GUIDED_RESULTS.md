# Phase 1 Language-Guided Results

Generated by `statistics/phase1_final_statistics.py` from the shared evaluator's per-case outputs. Do not edit tables by hand; rerun the script.

## Scope

Phase 1 reproduces **LViT-T** and **RecLMIS** on QaTa-COV19-v2 and MosMedData+ with seeds 1001, 1002 and 1003 (12 runs). The research advisor removed ProLearn from the study on 2026-10-03; it was not run in the main experiment. Phase 0 methods were not retrained, modified or extended.

## Data and protocol

| Dataset | Train / val / test | Test clusters | Manifest sha256 |
|---|---|---|---|
| QaTa-COV19-v2 | 5,716 / 1,429 / 2,113 | 474 | `e12e88a0b570ad14` |
| MosMedData+ | 1,746 / 437 / 546 | 86 | `5f2cbe3a7e1cf91c` |

- The Phase 1 manifests are byte-identical copies of the frozen Phase 0 manifests (plan §1.4 rule 2), so all five methods share the same train, validation and test samples.
- Every image has its paired report: the main comparison uses 100% of the available reports.
- Each method keeps its native text encoder and fusion: LViT-T uses frozen BERT-base token embeddings (first 10 tokens); RecLMIS uses its CLIP text encoder with 18 tokens.
- Both methods require text at training and at test time.
- Native architectures, losses, optimizers, schedules, batch sizes and patience were kept. Training augmentation is disabled by the text-safe adapter policy (flips and rotations can contradict laterality and location text).
- Checkpoint selection uses validation mean per-case Dice at threshold 0.5. Each selected checkpoint was evaluated once on the test set; a `test_started.json` marker blocks repeat evaluation.
- If a training loss is nonfinite, training stops and the best pre-event validation checkpoint is tested. The upstream loops have no finiteness check, so NaN parameters could never raise validation Dice and early stopping would select the same checkpoint.

## Reproduction gates

All seven gates from plan §1.3 pass for both methods: data (32/32/32), shape, overfit (training Dice LViT-T 0.9026, RecLMIS 0.9296), language-module gradient, validation inference (1,429 cases), text use (correct, null and shuffled text give different logits) and official check (LViT-T official-style QaTa run, best validation Dice 0.8067; RecLMIS strict load of the author checkpoint). Details: `methods/phase1_language_guided/gates/STATUS.md`.

## Evaluation

One shared evaluator (`evaluation/shared_evaluator.py`) scores every Phase 0 and Phase 1 run. Saved probability maps are resampled bilinearly to the original mask grid (QaTa 224x224, MosMed 512x512), thresholded at 0.5, and compared with the original masks, so HD95 and ASSD are in native pixels for every method. Resampling inverts each pipeline's own target-resizing geometry (Phase 1: corner-aligned `cv2.INTER_NEAREST`). The rule was fixed from the resize code and confirmed on validation masks without predictions. Each run is first re-scored at its stored resolution and reproduces its saved per-case metrics (maximum error below 1e-13).

Statistics follow Phase 0 exactly: per-case metrics are averaged across the three seeds; absolute 95% CIs use 10,000 bootstrap resamples of `source_id` clusters (images where no cluster exists). QaTa: 2113 cases in 474 clusters; MosMed: 546 cases in 86 clusters.

## Deviations and limitations

- ProLearn was removed from the study by the research advisor and was not run.
- An earlier launch (2026-09-16) used annotation-workbook splits that differed from Phase 0. Those runs are archived in `methods/phase1_language_guided/archive/xlsx_split_20260916/` and are not used.
- RecLMIS needs fairseq's float32 softmax, which would not build; `reclmis_compat.py` supplies that one function, matching fairseq 0.10.2. Upstream source is unchanged.
- Training augmentation was disabled for both methods (text-safe adapter policy).
- Phase 1 networks run at 224x224 (their native input). MosMed masks are 512x512, so Phase 1 MosMed results include a resolution cost that the 384x384 Phase 0 methods pay less of (see sensitivity table).
- Some QaTa subjects and MosMed studies cross the frozen splits (`methods/phase0_image_only/DATA_LIMITATIONS.md`); CIs resample by `source_id` cluster.
